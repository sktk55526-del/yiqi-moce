# 一起抹车 Web App

广东纸牌，好友同桌。适配安卓和苹果手机，可添加到手机桌面。

网页通过 GitHub Pages 发布，好友联机连接现有腾讯云 WebSocket 服务。
公开仓库仅包含浏览器端代码和资源，不包含服务端数据、管理员密码或签名材料。

## 开发与发布

需要 Node.js 22。执行 npm ci 和 npm run build，静态产物位于 dist。
推送到 main 后，GitHub Actions 自动构建并部署。仓库 Settings → Pages → Source 选择 GitHub Actions。

资源、安装清单及离线缓存支持仓库子路径。联机地址由 pwa/config.js 配置。
不要在前端配置中加入任何密钥或管理员密码。

## 使用

安卓：Chrome 菜单 → 安装应用/添加到主屏幕。
苹果：Safari 分享 → 添加到主屏幕。
首次联网加载完成后可离线人机练习；好友房需要联网。
网页更新仅在首页提示，不会自动刷新进行中的牌局。

不同域名、浏览器或安装入口可能分别保存昵称、偏好及牌局恢复信息。
切换发布地址前请结束当前牌局，并用新地址重新添加桌面图标。
